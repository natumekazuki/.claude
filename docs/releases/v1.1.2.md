# v1.1.2

未実施・未確認事項を一律に報告させる指示を整理しました。変更内容と実際の検証結果を短く伝え、実施していない確認や結果不明の処理を成功扱いしない原則は維持します。

## 変更

- [共通ルール](https://github.com/natumekazuki/.claude/blob/f4359cc901c02a2986fa96c3caab72c860bc6e09/CLAUDE.md)と開発・設計guide、README、hook、委譲guideから、未実施・未確認の報告項目や重複する説明を削除しました。
- UI・test review Skillの同種の報告要求も整理しました。必須確認と操作権限は変更しません。
- [Session Graph](https://github.com/natumekazuki/.claude/blob/f4359cc901c02a2986fa96c3caab72c860bc6e09/skills/session-graph/SKILL.md)の一律の未確認列挙と、review・全体test・統合・公開の未確認を並べる架空例を削除しました。実際の結果・確認対象・根拠・未解決の判断を扱う仕組みは維持します。
- 文書Skillの取り込み元を確認し、[ローカル生成の参照文書](https://github.com/natumekazuki/.claude/blob/f4359cc901c02a2986fa96c3caab72c860bc6e09/skills/natural-japanese/references/write.md)からlint未実行理由の報告要求を削除しました。外部由来の参照資料と取り込みrevisionは変更していません。共通の変更をCodex側にも反映しています。

## 互換性

指示と関連文書を整理するpatch releaseです。Skill名・導入入口、`review-test-value`のCLI・result・metadata・adapter・Git差分選択、Session Graphの保存・競合・cleanup、認証・操作権限、利用者データの維持契約は変更しません。新しい依存・設定・利用者データ移行はありません。repositoryのprivate設定は維持します。
