# v4.1.0

v4.0.8からの互換マイナー更新です。Claude Codeの共通指示を、禁止事項の列挙ではなく「何を守るか」「誰がそれを担うか」から判断する構成に変更しました。

## 作業で変わること

- [設計と実装](https://github.com/natumekazuki/.claude/blob/dbd4e76ff32c3eefec3971779464d55b91b02e37/docs/guides/design-decisions.md)では、既存機構とそのための状態・検査を外したとき、利用者や運用者が何を失うかを先に確かめます。必要な責務はフロントエンド・バックエンドとも既存の担当箇所を優先し、同じ理由で変わる判断を集約します。表示と認可などの異なる境界や、一度きりの変換には共通層を求めません。
- [UIの判断](https://github.com/natumekazuki/.claude/blob/dbd4e76ff32c3eefec3971779464d55b91b02e37/docs/guides/ui.md)では、空の補助欄を既定で用意しません。配置や既存の操作名でも伝わらず新たな説明が必要な場合は、対象・最短の文案・理由を差分単位でまとめ、実装前に明示承認を得ます。一語のバッジやtooltipも同じ扱いです。本文、読み上げ名、危険操作の確定前確認、失敗からの回復は機能の一部として残します。
- [変更test](https://github.com/natumekazuki/.claude/blob/dbd4e76ff32c3eefec3971779464d55b91b02e37/docs/guides/test-changes.md)では、旧実装を消した事実の確認と、権限のない利用者に情報を返さないなどの現役契約を分けます。前者だけのために恒久testを増やさず、後者は削除・移設の差分でも独立した読取専用担当が審査します。
- 作業報告は答えと受入に必要な根拠を先に伝えます。合意した残件や利用を左右する未確認は伝えますが、依頼外でしなかったことを並べる欄は作りません。WithMateの実呼出元・相談・保存後配送は[協同ガイド](https://github.com/natumekazuki/.claude/blob/dbd4e76ff32c3eefec3971779464d55b91b02e37/docs/guides/withmate-collaboration.md)、Workspaceの準備と復旧は[作業領域ガイド](https://github.com/natumekazuki/.claude/blob/dbd4e76ff32c3eefec3971779464d55b91b02e37/docs/architecture/subagent-workspace.md)から辿れます。

## 互換性と更新

Skill名、明示起動の文章Skill、変更test抽出器のCLI・metadata・resultは従来どおりです。Claudeのagent・tool制限とhook登録も変更しません。起動通知は共通入口だけを指し、判断本文はそこから必要時に読みます。

直接checkoutする端末は既定branchの更新後に新しいSessionを開始してください。手動配置では [導入と更新](https://github.com/natumekazuki/.claude/blob/dbd4e76ff32c3eefec3971779464d55b91b02e37/README.md#導入と更新)に従い、入口とガイド、個人Skill・agent・通知スクリプトを同じ版に揃えます。実設定、認証、既存の記録、外部管理Skillの移行や信頼登録の変更は不要です。
