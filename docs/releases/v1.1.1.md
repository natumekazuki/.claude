# v1.1.1

`review-test-value`の既存テストを補強し、指定commitの取り違えと、構文エラーを含むfileからの正常test recordの漏出を検出できるようにしました。本番処理と公開契約は変更しません。

## 変更

- [Git snapshot選択のtest](https://github.com/natumekazuki/.claude/blob/40732d365e36b51908687c29430ec96490070956/skills/review-test-value/scripts/test_extract_test_values.py)で、指定commit・現在HEAD・未コミットworktreeをそれぞれ別の内容にし、`--head <commit>`が指定した本文だけを取得することを確認します。
- [TypeScript/C#のsyntax error test](https://github.com/natumekazuki/.claude/blob/40732d365e36b51908687c29430ec96490070956/skills/review-test-value/scripts/test_extract_test_values_multilang.py)は、正常対照からtestを抽出してから、同じfileへ独立した構文エラーを追加します。異常時のexit 1、空の`tests`、`SOURCE_SYNTAX_ERROR`の存在を直接検証し、他diagnosticの同居は許容します。
- 対象3 testのmetadataを実際の検証境界へ合わせ、oracleを各repository内に存在する現行のGit snapshot・source adapter契約節へ揃えました。共通の変更をCodex／Claude双方へ反映しています。

## 互換性と更新

- 既存testとmetadataの修正のみを含むpatch releaseです。Skill名・導入入口、CLI、result `schema_version: 2`、metadata v2、adapter識別子、Git snapshot・transition、Session Graphの保存・競合・cleanup、認証・操作権限、利用者データの維持契約は変更しません。
- 新しい依存・設定・公開schema・fallback・利用者データ移行はありません。private repository内のGit sourceとGitHub Releaseで配布し、公開範囲は変更しません。配布版の公開と端末runtimeへの配置は別操作です。

## 検証と確認範囲

- 実装段階のWindows回帰suiteはPython 52件・多言語54件の全106件が成功し、skipはありません。
- 指定commitを無視して現在HEADを読む欠陥、およびsyntax error時の全record遮断を除去する欠陥を一時的に注入し、対象3 testが意図したassertionで失敗することを両repositoryで確認しました。確認用欠陥は復元済みです。
- task開始baseから変更testをGit差分抽出し、全recordの独立read-only価値審査を完了しました。oracle修正後の再抽出・局所審査で未解決の指摘はなく、両repositoryの対象2 fileは同一です。
- リリース準備ではrelease noteのみを追加し、検証済みのtest・本番処理は変更していません。本repositoryにGitHub Actions workflowはなく、CI成功は主張しません。統合後の確認はmaster上の対象commitで行います。
- runtime配置、新しいClaude sessionでの実運用は配布版の検証範囲に含めません。
