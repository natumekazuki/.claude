# v2.0.0

review-test-valueの一対多置換を旧新recordを保持して審査できるようにし、Memory・Character Affectの利用方針と、レビュー指摘の仕上げ・後追い判断を更新しました。

## 破壊的変更: 一対多置換のGit差分選択

- [Git差分選択の契約](https://github.com/natumekazuki/.claude/blob/2658bdc5bc5269daaf3a0a54a4e5e889e874b107/skills/review-test-value/references/git-selection-v1.md)に定める一対多置換では、従来の`RECORD_TRANSITION_UNRESOLVED`による停止から、旧recordの`DELETED.before`と各新recordの`ADDED.after`を保持した抽出成功へ変わります。
- 旧開始行の置換、保持行の複数の未対応新宣言への分散など、契約の条件を全て満たす場合だけを対象とします。内容・位置の候補が競合する場合、不正metadata、宣言外への投影、解析失敗等の停止を一律に抑制するものではありません。
- [回帰test](https://github.com/natumekazuki/.claude/blob/2658bdc5bc5269daaf3a0a54a4e5e889e874b107/skills/review-test-value/scripts/test_extract_test_values_multilang.py)では、旧新の全文・位置・metadataの保持と、working・staged・headの各snapshotの区別を確認します。実装はsymbol名や共通本文から存続を推測しません。
- `DELETED`は機能の廃止承認ではありません。抽出成功も意味上の審査完了ではなく、旧新全recordのread-only価値審査が引き続き必要です。

公開済みのGit選択・失敗契約を変更するため、v1.2.0からmajor versionを更新します。CLI引数、構造化resultのschema、metadata v2、source adapterの形式は変更しません。Skill名と導入の入口、Session Graphの保存・競合・cleanup契約も維持します。新しい依存やデータ移行はありません。従来の停止結果を前提とする利用手順は、新しい限定条件と全件審査の扱いを確認してください。

## 方針の更新

- [WithMate利用方針](https://github.com/natumekazuki/.claude/blob/2658bdc5bc5269daaf3a0a54a4e5e889e874b107/docs/guides/withmate.md): 本人による必要時の逐次想起、小さな経験・受け取りの自発記録、基本人格を保ったAffect反映を明確にしました。Affect連携episode、独立episode、一般Memoryの既存経路を使い、二重保存・棄却の迂回・架空event保存・権限拡張を認めません。
- [開発・review・統合の判断](https://github.com/natumekazuki/.claude/blob/2658bdc5bc5269daaf3a0a54a4e5e889e874b107/docs/guides/development.md): 採否・対応時期・統合可否を分離しました。必要で局所的に完結する不備は今回の仕上げとし、後追いには必要性、今分離する理由、延期可能性を求めます。任意改善や既存残件を一律に即時必須へ昇格させません。関連Skill・委譲guideも整合させています。

## 検証と確認限界

- 開発時の固定commitで、Windows上のPython・多言語回帰suite計111 tests、構文検査、差分checkが成功しました。変更test全4recordのbefore・afterを含む独立read-only審査を完了し、指摘はありません。統合で実装・test本文は変更していません。
- 後追い判断の文書上のケース、変更Skillの構文、既存hook出力を確認しました。統合時には双方の方針がREADMEに保持され、各guideがレビュー済み内容と一致することを確認しました。
- 共通のMemory・Affect方針について、Codex側では実際の想起、本人によるAffectと関連episodeの保存、同turn内の後続検索・読戻し、3入力×4条件の12応答の合成比較が実施されています。Claude側では方針・参照・呼出契約の整合を確認しており、Codex側の実施結果をClaude providerでの実動作確認とは扱いません。
- Affectに依存しない一般Memory／standalone episodeの新規保存、live配置後の新規sessionでの自然利用、Claude providerでの実挙動は未確認です。Issue-473の全受入完了やMemory改善効果の確認完了を意味しません。Issue-474の配置後の実案件での実効性も未確認です。

## 適用範囲と既知の残件
