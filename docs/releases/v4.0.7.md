# v4.0.7

WithMateの通常送信で、Model・Depthが原因で未受付になった場合の再送条件を明確にする互換修正版です。

## 変更内容

- [Session間の協同](https://github.com/natumekazuki/.claude/blob/5607191d5ccd5e1558248a1ffcbe9c92394e5db5/docs/guides/withmate-collaboration.md#通常送信と実行中の補足)で、Model・Depthが原因の未受付が確定したときだけ、送信元が宛先のカタログと選定方針に従って今回のModel・Depthを選び直し、新しい `requestId` で再送することを明記しました。適合候補がなければ不足を報告します。
- 受付結果が不明なときは再送せず、元の `requestId` と正確な宛先で `session.get_receipt` を照会する既存手順を、通常送信の説明へ集約しました。

## 互換性・更新時の注意

変更は協同ガイドのみです。WithMateの製品動作やMCP契約、自動代替、保存済み設定・権限、Skill名・配置入口は変更しません。既存homeへは対象文書の差分を反映し、実設定・認証・履歴等を上書きしないでください。

## 確認範囲

v4.0.6からの差分、採用された再送条件との照合、照会手順の集約、固定参照先、`git diff --check` を確認しました。[Codex #160](https://github.com/natumekazuki/.codex/issues/160) の検討では、不適合Model・Depthが未受付になり、適合候補を選び直した別IDの送信だけが完了することを確認しています。本版の確認では実送信を再試行しておらず、新規Claude Codeセッションでの適用も確認していません。
