# v4.0.8

WithMateでの親子Sessionの権限と返信参照の手順を、v7.0.1-preview.2の契約に合わせる互換修正版です。

## 変更内容

- [Session間の協同](https://github.com/natumekazuki/.claude/blob/163fc7476bdaacf11dec69a0e52b46571e422748/docs/guides/withmate-collaboration.md#実行条件の選定)で、通常子の権限は作成元の実行中Turnから解決し、通常送信では受付時の宛先の保存権限を使うと明記しました。作成・送信の引数で権限を上書きせず、Model・Depthの指定や作業の個別操作許可と区別します。
- `Reply To` は返信対象への参照として扱い、本文が文脈にない場合に限り必要な一通を取得します。宛先・実送信元・操作許可としては扱いません。Model・Depthが原因で未受付になった場合の再送条件は従来どおりです。
- 現行手順に不要な参照を整理しました。文章Skillの校正判断に必要な資料は、対応する上流の版と該当箇所に辿れるようにしました。

## 互換性・更新時の注意

変更は配布文書とコメントです。WithMate本体・MCP・Skillの動作や配置入口は変わりません。既存の個人設定、認証情報、履歴、外部管理Skill、WithMateの保存方針の変更や移行は不要です。
