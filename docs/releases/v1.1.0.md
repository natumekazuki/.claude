# v1.1.0

`review-test-value`のC# adapterで、test宣言に影響しないsymbol依存の条件付き処理を含むsourceを扱えるようにしました。未解決のtest宣言を診断なしで落とさない境界を保ち、root外内容の不抽出とsyntax diagnosticの検証も整えています。

## 変更

- [C# adapter](https://github.com/natumekazuki/.claude/blob/c69ec12c2a89128787c8d3a4fd8b64027e928b88/skills/review-test-value/scripts/adapters/csharp/Program.cs)は、inactive・elif・else・nestedを含む全分岐でtest宣言への影響がないと確認できる`#if` / `#elif` groupを診断対象から外します。同一fileの独立したtestと、別fileの変更testを引き続き抽出します。共通資産の[Codex Issue #114](https://github.com/natumekazuki/.codex/issues/114)への同等対応です。
- test属性候補、宣言headerとの交差、字句・scopeの不確実性があるgroupは`TEST_DECLARATION_UNSUPPORTED`を維持します。除外するtest宣言の全体と先行metadataを内部診断選択範囲へ含め、group外の本文・metadata変更もworking・staged・headで無診断成功にしません。公開diagnosticの`line`はgroup開始位置を維持します。[対応範囲](https://github.com/natumekazuki/.claude/blob/c69ec12c2a89128787c8d3a4fd8b64027e928b88/skills/review-test-value/references/source-adapters-v1.md)を更新しました。
- [root外pathの公開CLI test](https://github.com/natumekazuki/.claude/blob/c69ec12c2a89128787c8d3a4fd8b64027e928b88/skills/review-test-value/scripts/test_extract_test_values.py)で、空の`tests`と外部test本文・symbolの不在を直接確認します。[Issue #2](https://github.com/natumekazuki/.claude/issues/2)への対応です。
- [多言語test](https://github.com/natumekazuki/.claude/blob/c69ec12c2a89128787c8d3a4fd8b64027e928b88/skills/review-test-value/scripts/test_extract_test_values_multilang.py)のsyntax claimを、`SOURCE_SYNTAX_ERROR`の存在と部分record不出力へ合わせました。診断の専一性を保証するという説明はしません。[Issue #3](https://github.com/natumekazuki/.claude/issues/3)への対応です。

## 互換性と更新

- C# sourceの対応範囲を広げるminor releaseです。CLI引数、result `schema_version: 2`、metadata v2、adapter識別子とGit snapshot・transitionの契約を維持します。Skill名・導入入口、Session Graphの保存・競合・cleanup、権限・認証・既存利用者データの維持契約は変更しません。
- 未解決test、syntax error、metadata不正、削除側の未対応宣言、snapshot対応不明の診断を一括抑制しません。test属性名と同名の通常identifierは保守的な診断対象になり得ます。完全なMSBuild構成評価、aliasの意味解決、runtime discoveryは対象外です。
- 既存の配置方法で`skills/review-test-value/`を更新してください。新しい依存・設定・利用者データ移行はありません。private repository内のGit sourceとGitHub Releaseで配布し、公開範囲は変更しません。配布版の公開と端末runtimeへの配置は別操作です。
