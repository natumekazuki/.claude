# v4.0.2

共通運用の不要な不揃いと重複説明を整理し、製品固有の契約を保持する互換修正版です。

## 変更内容

- [WithMate利用guide](https://github.com/natumekazuki/.claude/blob/62d7cb4c8edfa0cf9de55c04a5f3630f621f87e6/docs/guides/withmate.md)のCharacter表現と成果物境界を短い共通説明へ集約しました。帰属・事実・権限・検証結果の扱いは変更しません。
- [協同guide](https://github.com/natumekazuki/.claude/blob/62d7cb4c8edfa0cf9de55c04a5f3630f621f87e6/docs/guides/withmate-collaboration.md)で、返信時の必要説明と上位応答契約を揃え、runtimeが自己説明する操作schemaの重複や個別例を削減しました。宛先・実行条件・配置・結果不明時の判断は現在のruntime契約を参照します。
- [委譲原則](https://github.com/natumekazuki/.claude/blob/62d7cb4c8edfa0cf9de55c04a5f3630f621f87e6/CLAUDE.md)で、目的・出所・合意・権限の区別と必要時の原文引用を共通方針へ揃えました。
- [UI guide](https://github.com/natumekazuki/.claude/blob/62d7cb4c8edfa0cf9de55c04a5f3630f621f87e6/docs/guides/ui.md)の検証・共有に関する重複注意を集約しました。視覚確認をtest/buildで代替しないことと操作権限の境界は維持します。

## 互換性・更新時の注意

Skill名・配置入口・抽出CLI/result/metadata・通常Session履歴・Graph/Glossary、承認・sandbox・Reviewer・native委譲等の製品固有契約とデータ保護は維持します。実設定・認証・履歴の置換や新しい同期・検証基盤は追加していません。既存homeへは対象文書の差分だけを反映してください。

## 確認範囲

3製品の意味比較、局所静的確認、独立reviewと指摘修正確認を実施しました。C/Oの変更Skillではvalidator、別cwdからのCLI解決と代表的な公開CLIテストを確認しました。対象11文書のhome差分配置とsource一致も確認しています。

local環境の全回帰はTypeScript adapter依存不足で中断し、旧呼出方式でも同じ失敗を確認しています。全回帰成功とは扱いません。新provider Sessionでの読込、実配送、モデル行動の改善を配置一致から保証するものではありません。
