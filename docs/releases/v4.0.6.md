# v4.0.6

アプリ開発時に適用する実装規約と検査の判断基準を、Codex版と揃える互換修正版です。

## 変更内容

- [CLAUDE.mdの条件付き参照](https://github.com/natumekazuki/.claude/blob/c27255b0b11d7d46bfcf526e0256fce150c73224/CLAUDE.md#条件付き参照)から、アプリ開発時に[実装規約の基本セット](https://github.com/natumekazuki/.claude/blob/c27255b0b11d7d46bfcf526e0256fce150c73224/docs/guides/development.md#実装規約の基本セット)を適用するようにしました。新規開発・初回整備では全体を扱い、通常の変更では関連範囲に絞ります。対象repositoryの入口から規約と検査の実行方法を辿れるようにします。
- 基本セットでは、書式・命名・lintと該当する型検査、責務ごとの配置と依存方向、公開API・境界の契約コメント、重要な正常時・失敗時のテストを定めます。既存の設定・ツール・検査を優先し、機械で判定できる違反は機械検査にします。
- commit前にはstaged内容を高速に検査し、push前には対象commitに該当する型・依存の検査と単体テストを行います。merge前の確認とCIの要否は実際の統合経路に必要な保証で判断し、Git hookを使う場合は有効化方法を示し、手動実行やCIと同じ検査本体を呼びます。検査の新設時は正常例と代表的な違反例の両方で確認します。

## 互換性・更新時の注意

Skill名・配置入口、抽出CLI・result・metadata schema・adapter・Git差分選択、Session Graphの利用方針、操作承認の契約は変更しません。アプリへのGit hook設置、実装着手やGit操作を一律に停止する機構、個人設定の変更は含みません。既存homeへは対象文書の差分を反映し、実設定・認証・履歴等を上書きしないでください。
