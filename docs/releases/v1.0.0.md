# v1.0.0

Claude個人設定の初期正式版。個人共通ルール、6 Skill、Sonnet/Opus担当、権限・MCP・hook・記憶方針を、独立した設定資産として提供する。

## 提供内容

- [導入・更新とrepository運用](https://github.com/natumekazuki/.claude/blob/ff35292d659148482df7b9c467ca6e7ec1988632/README.md)、[個人共通ルールの入口](https://github.com/natumekazuki/.claude/blob/ff35292d659148482df7b9c467ca6e7ec1988632/CLAUDE.md)と作業別guide。
- Session Graph、review-test-value、UI設計、RelayGraph、日本語技術文書、自然な日本語の6 Skill。日本語技術文書と自然な日本語は明示起動のみ。

- [設定例](https://github.com/natumekazuki/.claude/blob/ff35292d659148482df7b9c467ca6e7ec1988632/settings.example.json)。acceptEdits、WebSearch/WebFetch、model別effort、非fork委譲・depth 1・通常Agent同時上限24、共通ルールの再通知hook、auto memory無効化。

配布物はtagに対応するGit管理source一式であり、private repository内のGitHub Releaseから取得する。端末localの実設定・認証・Session binding・Memory・履歴・外部管理Skill・plugin本体・依存生成物は含めない。既存設定を丸ごと上書きせず、READMEの導入・更新方法に従う。第三者のLICENSE・NOTICEは同梱する。

## 互換性の維持対象

- 利用者が直接使うSkill名: `session-graph`、`review-test-value`、`design-ui-information`、`relaygraph`、`japanese-tech-writing-review`、`natural-japanese`。ユーザーhome直下の`~/.claude/`へ配置し、各Skillの実pathから同梱資産を解決する導入の入口。
- [review-test-value](https://github.com/natumekazuki/.claude/blob/ff35292d659148482df7b9c467ca6e7ec1988632/skills/review-test-value/SKILL.md)のCLI/result（`schema_version: 2`）、[審査用metadata v2](https://github.com/natumekazuki/.claude/blob/ff35292d659148482df7b9c467ca6e7ec1988632/skills/review-test-value/references/comment-format-v2.md)、[source adapter v1](https://github.com/natumekazuki/.claude/blob/ff35292d659148482df7b9c467ca6e7ec1988632/skills/review-test-value/references/source-adapters-v1.md)、[Git差分選択 v1](https://github.com/natumekazuki/.claude/blob/ff35292d659148482df7b9c467ca6e7ec1988632/skills/review-test-value/references/git-selection-v1.md)。Python・TypeScript・C#のsource declarationを対象とし、runtime collection・動的生成caseの展開は行わない。抽出後の全recordのread-only価値審査は省略しない。
- [Session Graph](https://github.com/natumekazuki/.claude/blob/ff35292d659148482df7b9c467ca6e7ec1988632/skills/session-graph/SKILL.md)の`snapshot`・`save`・`cleanup` CLI、既存Mermaid共有記録の読書き、同helperを使うlocal process間の原文比較・競合拒否・保存と明示対象だけのcleanup。成功・競合・入出力失敗を区別し、記録や利用者データを無断で破棄しない。

内部実装、文書の表現・構成、fixture、開始値としてのmodel/effort全体を固定するものではない。modelの提供・費用・出力品質、WithMateの製品動作は本repositoryの互換性保証に含めない。実設定・認証・既存Memory・共有記録と操作の承認境界はtagの有無にかかわらず保護する。配布版の`v1.0.0`と、同梱するmetadata/result/adapter等の形式versionは別の識別子である。

## 確認環境と結果

確認環境はNative Windows、Claude Code 2.1.296。Python 3.10以降はSession Graph helper、Python 3.11以降とGitはreview-test-valueに必要となる。TypeScriptにはNode.js/npmとlockfileに従う依存、C#には.NET 8実行環境と対応SDKが必要。hookはWindows PowerShell 5.1・PowerShell 7で確認済み。MCP登録例はPowerShell 7.3以降を対象とする。未検証の最低Claude versionや他OS対応は保証しない。

- Session Graphの14test、review-test-valueの101testは開発時に成功し、skipなし。変更testの独立read-only価値審査は完了し、統合ブロッカーなし。release準備でこれらのSkill・testを変更していないため、既存結果を適用し、全suiteを再実行していない。
- Claude側のWithMate接続、auto memory off、Skill/Agent/hookの基本起動・適用はユーザー確認済み。親による個別条件の全実測へ読み替えない。
- release準備では設定例のJSON、参照、差分、Git管理対象と配布除外を確認した。実設定・認証・Memory・外部管理Skillは変更していない。

## 既知の制約と後追い

Native Windowsのshell commandはCodexと同等のOS隔離を提供しない。acceptEditsやWebのallowは、shell・MCP・外部writeの包括承認ではない。Opus親からOpus子を起動しない規約は維持するが、その機械的な完全防止guardは提供しない。委譲の同時上限は通常のAgent起動の設定であり、resume・workflow・agent team等を含む全実行の一律保証ではない。

model/effortの性能等価・最適性、全Agent条件・承認dialog・resume/compactの全経路、WithMate Memoryの新規保存・自然な想起・効用は未実証。auto memoryの無効化とWithMateの効用確認は別に扱う。auditのClaude対応、追加playwright、任意のCI・installer・更新scriptは本版に含めない。
