# v6.0.0

WithMate 7.1に合わせ、Session Graphの利用規則・専用Skill・配布許可・起動時の案内を廃止します。旧経路の互換や記録の移行はありません。Claudeの共通指示を案内する起動hook、native agent、auto memory設定は従来どおりです。

## WithMateを使うとき

- 自分が作業を続けるために必要なメモはSessionFolderに、他Sessionの判断に必要な資料はCrew Folderに置きます。共有するときは変更点と資料の参照を通常送信で届けます。毎Turnの記録や、既存の仕様・PRの二重管理は不要です。[保存と配送の基準](https://github.com/natumekazuki/.claude/blob/cb1164909c7175b5d9ea0a667948f6b662e8a730/docs/guides/withmate.md#sessionfolderとcrew-folder)
- 持続する前提・制約・必須ゴールが変わった場合だけ、自SessionのSession Instructionsを読み、無関係なユーザーの記述を残して全文を保存します。変更が反映されるのは次の新規Turnからで、他Sessionには共有されません。read-onlyの担当でもこの限定更新はできますが、記録禁止の明示指示を優先します。[Session Instructionsの更新条件](https://github.com/natumekazuki/.claude/blob/cb1164909c7175b5d9ea0a667948f6b662e8a730/docs/guides/withmate.md#自sessionのsession-instructions)
- `main`／`master` への統合はGitHub PRを使います。それ以外の宛先はすべてWithMateローカルPRに提出し、提出元と宛先のcommitの組をユーザーがGUIで承認するまで止まります。所定の経路を利用できなければ、そのmergeだけを保留します。ローカルPRのChecksはWithMateのOS権限で動作し、提出や承認はその実行許可を兼ねません。[merge先別の手順](https://github.com/natumekazuki/.claude/blob/cb1164909c7175b5d9ea0a667948f6b662e8a730/docs/guides/development.md#withmateでのmerge)

## 共通設計と並列実装

- [設計ガイド](https://github.com/natumekazuki/.claude/blob/3034650864bd28085573bc2d6d24359bb889231b/docs/guides/design-decisions.md#必要な責務をどこで実装するか)では、実装前に影響範囲と具体的な利用先をたどり、共有する処理の提供元と契約を決めます。共通実装が必要なら先に用意し、各利用側を接続します。
- [並列実装の委譲](https://github.com/natumekazuki/.claude/blob/3034650864bd28085573bc2d6d24359bb889231b/docs/architecture/subagent-workspace.md#並列実装の割当てと受入)では、親が共通実装の唯一の担当、利用側、契約と受渡し順を割当て前に決めます。途中で重複が分かった場合は該当部分だけを止めて割り当て直し、受入時には利用側が共通実装を使うことを確認します。

## 更新時の注意

手動配置で旧版の `skills/session-graph/` が残っている場合は、旧配布物と個人の変更を区別し、旧配布のSkillをClaudeの探索先から外してください。個人の設定・記憶や端末の方針ファイルを置き換える必要はありません。WithMateを使わない場合は専用folderやAPIを必要とせず、統合は対象repositoryの手順と既存の承認条件に従います。
