# v4.1.1

v4.1.0からの互換パッチ更新です。依頼の結果に必要な判断と確認は残し、任された手段に重ねて承認を求めたり、規約の更新だけで一律の比較を求めたりする運用を改めました。

## 作業で変わること

- [共通の作業規約](https://github.com/natumekazuki/.claude/blob/1351cdbfa369edb88e1b8cd1fd5912ca66a7d33c/CLAUDE.md)では、依頼された結果と任された範囲を基準に手段を選びます。根拠が足りなければ結論を限定し、権限がなければその操作だけを保留します。
- [配布物の確認](https://github.com/natumekazuki/.claude/blob/1351cdbfa369edb88e1b8cd1fd5912ca66a7d33c/README.md#配布物の確認)は変更の影響に合わせます。対照例・条件の一致・生成比較は一律の受入条件にしません。比較を依頼された場合は、問いに必要な条件を選び、揃わない条件が結論に与える影響を示します。
- [設計の判断](https://github.com/natumekazuki/.claude/blob/1351cdbfa369edb88e1b8cd1fd5912ca66a7d33c/docs/guides/design-decisions.md#誰の判断が必要か)と[UIの補助説明](https://github.com/natumekazuki/.claude/blob/1351cdbfa369edb88e1b8cd1fd5912ca66a7d33c/docs/guides/ui.md#主内容と補助説明の境界)では、既に任された範囲と新たな判断を要する変更を分けます。未合意の共有契約や必要な新規の補助説明に対する承認は維持します。

## 互換性と更新

破壊・公開などの操作承認、情報保護、既存の必須CIは変わりません。Claude Codeの設定・hook・agent・Skillの変更やデータ移行はありません。既存の [導入と更新](https://github.com/natumekazuki/.claude/blob/1351cdbfa369edb88e1b8cd1fd5912ca66a7d33c/README.md#導入と更新) に従って配布文書を更新し、新しいSessionを開始してください。実設定・認証・既存記録を置き換える必要はありません。
