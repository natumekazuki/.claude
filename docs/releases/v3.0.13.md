# v3.0.13

Codex PR #143と同じ目的で、共通ルールを整理し、依頼の意図・有効な合意・用途に沿った出力を優先する方針へ揃えました。

## 変更内容

- [共通入口](https://github.com/natumekazuki/.claude/blob/4e129583fbae789df56cd8614544be971d647ef3/CLAUDE.md)に、相談・訂正時の理解、情報選別、必要な不足と不要な留保の区別をまとめました。追加指示・Compact後も置換されていない要件を保ち、途中報告と最終応答の役割を分けます。
- [開発guide](https://github.com/natumekazuki/.claude/blob/4e129583fbae789df56cd8614544be971d647ef3/docs/guides/development.md)と[設計guide](https://github.com/natumekazuki/.claude/blob/4e129583fbae789df56cd8614544be971d647ef3/docs/guides/design-decisions.md)を縮小し、責務からの削減、草案と採用、維持境界、指摘の分類と統合判断を整理しました。
- [WithMate guide](https://github.com/natumekazuki/.claude/blob/4e129583fbae789df56cd8614544be971d647ef3/docs/guides/withmate.md)で、技術説明・進捗・最終報告でもCharacterの着眼点・関心・反応を表し、成果物本文・引用とは文体の境界を保つ方針を明記しました。
- [Session Graph Skill](https://github.com/natumekazuki/.claude/blob/4e129583fbae789df56cd8614544be971d647ef3/skills/session-graph/SKILL.md)は、記録・復元の判断へ絞り、取得・更新・属性の詳細をruntime契約へ集約しました。
- [natural-japanese](https://github.com/natumekazuki/.claude/blob/4e129583fbae789df56cd8614544be971d647ef3/skills/natural-japanese/SKILL.md)は、文書型や雛形の項目を用途に応じて選びます。明示要件、事実保持、選択modeの検査は維持し、write参照とNOTICEも揃えました。
- [README](https://github.com/natumekazuki/.claude/blob/4e129583fbae789df56cd8614544be971d647ef3/README.md)に、会話・Skill利用時の前後応答比較と、受け手の再説明・選別負担を含む確認観点を追加しました。

## 互換性

互換性を保つ指示・説明の修正です。Skill名、導入・配置の入口、review-test-valueのCLI・metadata・adapter、Session GraphのMCP利用方針と操作権限は維持します。Claude固有のSkill起動policy、model・tool・設定形式、接続案内、natural-japaneseの独立保守方式を保ち、Codex固有のmodel指示fileや同期scriptは追加しません。実設定・認証・外部managed Skill・既存Memory・Graphは変更しません。

## 確認

変更差分と製品固有部分、32件のlocal文書参照、差分check、Session Graph Skillの形式を確認しました。natural-japaneseはClaude固有frontmatterと明示起動policyを別途確認し、既存hookのSessionStart・SubagentStartについてJSON出力を実行確認しました。

移植元では通常会話9場面とSkill利用3場面の前後24応答、実Character4場面の前後8応答が比較されています。これらは条件保持の標本であり、Claude固有modelでの品質向上の実証ではありません。今回のClaude側確認は配布物の静的整合とhook実行であり、live配置、新規Claude SessionでのSkill発見・MCP接続・応答の前後生成比較は実施していません。
