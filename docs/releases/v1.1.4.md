# v1.1.4

WithMate 6.3.29の利用環境に合わせてMemoryの記録・参照方針と接続案内を整理し、規約の不要な再読と毎promptの再通知を減らしました。

## 変更

- [WithMate利用方針](https://github.com/natumekazuki/.claude/blob/83166332afd7b913e9fa4ce37e9aa6592d87ba80/docs/guides/withmate.md)で、日常の小さな事実・好み・共有episodeも記録対象とし、話題の開始・切替・再開時に関連Memoryを能動的に参照する方針を明確にしました。想起と新規保存を分け、毎turnの件数ノルマは設けません。
- [接続案内](https://github.com/natumekazuki/.claude/blob/83166332afd7b913e9fa4ce37e9aa6592d87ba80/README.md#mcp接続)をSessionへ自動供給されるmanaged HTTP接続に揃えました。設定例の手動登録を除き、STDIOは開発・診断用途に分離しました。
- [共通ルール](https://github.com/natumekazuki/.claude/blob/83166332afd7b913e9fa4ce37e9aa6592d87ba80/CLAUDE.md)は同じ作業で把握できる既読規約を再利用し、新規適用・更新の兆候・文脈欠落時に必要な対象だけを読み直します。
- [Session Graph](https://github.com/natumekazuki/.claude/blob/83166332afd7b913e9fa4ce37e9aa6592d87ba80/skills/session-graph/SKILL.md)の起動条件を作業開始・中断からの再開・Compact復元と要求・制約・承認・判断・状態の変化へ整理しました。既存内容だけの説明・確認・言い換えは除外し、短い承認や訂正の記録は維持します。
- [設定例](https://github.com/natumekazuki/.claude/blob/83166332afd7b913e9fa4ce37e9aa6592d87ba80/settings.example.json)からUserPromptSubmitの共通ルール再通知を削除し、SessionStart・SubagentStartは維持します。

## 互換性と適用

利用指示と接続説明を改善するpatch releaseです。Skill名・導入入口、review-test-valueのCLI・result・metadata・adapter・Git差分選択、Session Graphの保存・競合・cleanup契約は変更しません。Memoryの保存scope・重複確認・機密保護・操作権限、auto memory無効化とrepositoryのprivate設定を維持します。自動想起機構や新たな保存基盤は追加しません。

配布物の取得だけで端末localの設定は更新されません。既存の実設定・認証・Memory・共有記録を保持し、必要な差分だけを配置してください。接続URLと短命tokenは永続設定へ保存しません。

## 検証

- 最新のmasterを取り込んだ状態で、Windows PowerShell 5.1／PowerShell 7のSessionStart・SubagentStart出力、計4件とSkill validator、差分の形式確認が成功しました。
- 設定例のJSON構文と変更対象外の設定保持、Codex／Claude共通方針の整合を確認しました。共通の起動条件は、説明、短い承認、否定条件、継続turn、Compact復元、保存競合の6ケースを独立したモデル判断試行で確認しました。
- 配布元の静的確認・hook実行と、実配置後のSession lifecycle・HTTP接続・保存想起頻度・読込削減効果の確認は区別しています。後者は本リリースの検証結果には含めません。
